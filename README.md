# Centoro Admin Panel

A comprehensive, modern, and responsive administrative dashboard built for **Centoro Enterprise**. This frontend application provides a centralized hub for managing daily operations, tracking financials, handling CRM, and monitoring real-time company progress.

## 🔗 Related Repositories
*   **Backend API:** [Link to your Centoro/api repo] (e.g., https://github.com/Centoro/api)

## 🚀 Features

*   **Dynamic Dashboard:** Real-time overview of Revenue (Received vs. Outstanding), Active Projects, and Open Complaints.
*   **Financial Tracking:** Company Year Progress charts (2024-2026 targets) and live Exchange Rates (Base: ZAR).
*   **Operations Management:** Modules for Projects, Job Cards, Invoices, Accounting, and Vouchers.
*   **CRM & People:** Client management, Staff directory, Payroll, Client Chats, and Email/SMS centers.
*   **Global Time Zones:** Live time tracking for Johannesburg, London, and New York.
*   **Company Calendar:** Integrated scheduling for active job cards and events.

## 🎨 UI/UX Design
*   **Theme:** Dark mode optimized with a sleek navy/slate aesthetic.
*   **Accent Colors:** Vibrant orange/gold for primary actions and brand identity.
*   **Status Indicators:** Color-coded metrics (Green for received/positive, Red for outstanding/alerts, Blue for active).
*   **Layout:** Fixed sidebar navigation with a fluid, grid-based main content area.
